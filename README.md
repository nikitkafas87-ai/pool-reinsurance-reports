# Pool Reinsurance Reports

Static GitHub Pages site for pool reinsurance check reports.

Expected public URL:

`https://nikitkafas87-ai.github.io/pool-reinsurance-reports/`

## Structure

- `reports/dev/` - Dev/Test pool check HTML reports.
- `reports/prod/` - Prod pool check HTML reports.
- `cache/dev/` - Dev/Test cache snapshots as sanitized HTML.
- `cache/prod/` - Prod cache snapshots as sanitized HTML.
- `data/reports.json` - Site manifest for reports.
- `data/cache.json` - Site manifest for cache snapshots.

Do not publish raw cached questionnaires, API keys, request bodies, or personal data.
